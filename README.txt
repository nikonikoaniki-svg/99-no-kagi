九九のかぎ — 試作版

【起動】
index.html を Chrome / Edge などのブラウザで開いてください。
インターネットは不要です。GitHub Pages にそのままアップロードできます。

【学習のながれ】
1. しきづくり（たし算→かけ算、答えは求めない）
2. ひっくりかえそう（小さい九九で交換法則）
3. なかまをみつけよう（複数正解・フェイクあり）
4. 10このかぎをみつけよう（暗記不要）
5. たしてつくろう
6. ひいてつくろう
7. たす？ひく？
8. 九九のちからだめし（正解で81マスマップを開放）

偶数ルートを標準に、奇数ルートを別に選べます。
九九マップの黄色は10個の鍵、✓は力試しで自力正解したマスです。
称号は開放マス数に応じて10段階で上がります。
ブラウザの保存データは、同じブラウザ・同じ場所で開いた場合に使用できます。

試作版の注意：学校で使う前に端末・画面サイズで表示と操作を確認してください。
